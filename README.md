# TopoTanks: Real Earth Topographic Artillery

## Overview
TopoTanks is a retro-inspired turn-based artillery duel game that transforms real-world topographic elevation profiles into dynamic, destructible 2.5D heightfield battlegrounds. Built in Google AI Studio using the Google Maps Platform, the application queries live elevation samples along geodesic transects across iconic geological landmarks—such as Mount Fuji, the Grand Canyon, and Mount Everest—converting real geospatial data into playable combat terrain with real-time ballistics, wind physics, dynamic cratering, and synchronized satellite deployment views.

## Google Maps Platform Products & Features
* Maps JavaScript API
* Elevation API (`ElevationService`)
* Dynamic Maps (Satellite & Hybrid Imagery)
* Advanced Markers (`AdvancedMarkerElement`)
* Polylines & Geodesic Paths
* React Google Maps Library (`@vis.gl/react-google-maps`)
